The campaign maintains a consistent, public update feed through the official X account **@AlexSchnellPA3**. This feed is the primary channel for announcements, event information, and commentary from Alex Schnell on issues affecting PA-3. Following it requires no special access — updates are designed to be visible and accessible to any resident.

## Embedded X feed

The campaign website includes a dedicated updates page powered by an embedded Elfsight feed that pulls posts directly from @AlexSchnellPA3. The feed displays posts in a clean, readable format and refreshes automatically, so visitors always see the latest content without needing to reload the page.

Importantly, **no X account is required** to view the embedded feed. Any resident can visit the campaign website and browse the full update timeline without logging in or creating an account.

If the embedded feed does not load — for example, due to a browser extension or network restriction — you can view the profile directly at [xcancel.com/AlexSchnellPA3](https://xcancel.com/AlexSchnellPA3), a privacy-friendly alternative that does not require an X account.
